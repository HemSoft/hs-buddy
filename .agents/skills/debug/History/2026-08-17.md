# 2026-08-17

## 09:34 - Diagnosed blank screen on Aspire debug startup

App showed a blank screen when launched via `scripts/runAspire.debug.ps1`. Connected over CDP (port 9222) and found `ReferenceError: require is not defined` at `node_modules/.vite-electron-renderer/fs+promises.mjs:3`, with `#root` empty.

Root cause: `cron-parser` (CJS) re-exports `CronFileParser`, which uses `fs`/`fs/promises`. Vite pre-bundles cron-parser into the renderer's `.vite/deps`, hoisting the lazy `require('fs')` calls into static top-level imports. `vite-plugin-electron-renderer` (enabled by `renderer: {}` in `vite.config.ts`) then shims all Node builtins with `require()`-based wrappers — but this renderer runs `nodeIntegration: false`, so `require` is undefined and module evaluation aborts, preventing React from mounting.

Fix: removed the `renderer: {}` option from the `electron()` plugin in `vite.config.ts` (the renderer never uses Node builtins in production code). Vite now applies `cron-parser`'s own `browser` field (`fs: false`), stubbing `fs` to an empty module. Also set `base: './'` explicitly since the removed plugin used to provide it for `loadFile` in production. Verified: renderer mounts with full UI, no exceptions; `vite build` and lint/knip/typecheck all pass.
